# 일정 도구 교체 회고

지난주 샘플팀에서 일정 관리 도구를 바꿨다. 도구 기능 비교에 이틀을 썼는데, 정작 문제는 누가 일정을 입력하느냐였다.
입력 담당이 정해지지 않은 상태에서는 어떤 도구를 골라도 같은 문제가 반복된다.

## 이게 어디에 붙나

- 질문: q-001
- 판단: 도구 비교보다 입력 담당을 먼저 정한다
- 다음: 다음 도입 회의 첫 안건을 입력 담당으로
- 출처: 회의 메모

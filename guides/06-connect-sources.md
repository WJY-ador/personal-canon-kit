# 06. 자료 연결

이 버전은 **내가 고른 폴더·파일 1종**을 읽는 것까지입니다. 계정 연결·자동 수집은 없습니다.

## 순서

1. 읽어도 되는 범위에 동의 — 전체 디스크가 아니라 한 곳만.
   ```bash
   python3 canon.py consent --read ~/notes
   ```
2. 자료 등록 — 이름은 내 말로.
   ```bash
   python3 canon.py source add ~/notes --label "업무 메모"
   ```
   모델 전송을 허용하는 자료면 `--model-send` 를 붙입니다(기본은 안 보냄).
3. 그 안의 파일 1편을 기록으로 — `record add --file`.

## 빼 둘 것

토큰·비밀번호·회사 기밀·타인 발화·메신저 내용은 연결 범위에 넣지 마세요. 섞여 있으면 그 파일만 다른 폴더로 옮긴 뒤 연결합니다.

## 자료 폴더를 옮겼다면

`doctor` 가 `DATA-SOURCE 경고` 로 알려 줍니다. 새 위치에 `consent --read` 후 `source add` 로 다시 등록하세요. 이미 만든 기록은 데이터 폴더에 원문이 복사돼 있어 그대로 남습니다.

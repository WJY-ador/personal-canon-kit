# 09. 호스팅 판 — 연결하고 첫 하루

호스팅 판은 설치가 없습니다. 내 ChatGPT·Claude 구독으로 서버에 연결해 기록·후보를 남기고, 웹에서 보고 결정합니다. 모델 호출은 서버에 없고 내 구독만 씁니다.

## 1. 연결

| 어디서 | 어떻게 |
|---|---|
| Claude (claude.ai) | 설정 › 커넥터 › 커스텀 커넥터 추가 → 주소 `https://personal-mycrm.onrender.com/mcp` → 로그인 창에서 Google 또는 이메일 코드 |
| Claude Code | `claude mcp add --transport http my-crm https://personal-mycrm.onrender.com/mcp` 뒤 `/mcp` 에서 로그인 |
| ChatGPT | Developer Mode 의 커넥터 추가(같은 주소). 2026-10 기준 Business 이상에서 쓰기 도구를 허용합니다 — Plus/Pro 는 확인 전 |
| 웹 | `https://personal-mycrm.onrender.com/` → [로그인]. 같은 이메일이면 대화와 웹이 한 계정입니다 |

처음 로그인하면 계정이 만들어집니다. 무료 서버라 15분 쉬면 잠들어요 — 첫 응답이 30~60초 걸릴 수 있습니다.

**표시 이름을 먼저 정합니다.** 웹에 처음 들어가면 이름 입력 화면이 뜹니다. 실명이 아니어도 되고, 다른 사람에게 보이지 않고 운영자 화면에도 나오지 않습니다. 표시 이름을 정하기 전에는 대화에서 기록·후보 같은 쓰기를 할 수 없습니다(읽기·도움말·문의는 됩니다). 이미 쓰던 계정도 다음 웹 로그인 때 한 번 정합니다.

## 2. 첫 하루 — 네 마디면 됩니다

1. **기록** — 대화에서 "오늘 있었던 일 기록 남길게. …" 라고 말합니다. AI 가 내 말을 **그대로** 저장합니다(다듬지 않음).
2. **후보** — "후보 뽑아 줘". AI 가 기록에서 판단이 될 만한 문장을 최대 3개 뽑고, 각 문장의 **근거 구절**을 원문에서 글자 그대로 가져옵니다. 원문에 없는 구절은 서버가 거절합니다.
3. **대조** — 웹 `오늘` 탭 → [원문과 대조하기]. 새 탐색 화면(새 계정은 처음부터)에서는 「나」 홈의 [오늘 할 일]로 엽니다. 버튼 옆 숫자가 아직 안 정한 문장 수입니다. 후보 문장 옆에 원문이 형광펜과 함께 뜹니다. [내 판단으로 남기기] · [고쳐서 남기기] · [남기지 않기] · [건너뛰기].
4. **질문** — 같은 종류의 판단이 모일 것 같으면 "이 질문 남길게: …". 그 뒤 후보는 질문 밑에 쌓입니다. 질문은 나중에 정해도 됩니다.

## 3. 하고 싶은 일 → 이렇게 말하세요

대화에서 말하면 AI 가 알맞은 도구를 부릅니다. 예시 문장은 그대로 따라 하지 않아도 됩니다 — 뜻이 같으면 됩니다.

「결과가 보이는 곳」은 화면 꼴에 따라 다릅니다. **새 탐색을 수락하기 전**에는 4절의 다섯 탭(오늘·질문·기록·구조·지도)을 씁니다. **수락한 뒤**에는 탭 줄이 「나」 · 내 탭 · 「오브젝트」 · 지도가 되고, 「구조 정의」 보기는 계정 메뉴 「내 구조 설정」으로 옮깁니다. 표의 「오늘 탭」은 「나」 홈의 [오늘 할 일]로 엽니다. 새로 가입한 계정은 처음부터 수락한 상태입니다. 사람·출처 요약/반응·연결 장치·활동·승인 대기는 수락한 뒤에만 화면에 보입니다.

| 하고 싶은 일 | 이렇게 말하세요(예) | 어디서 | 결과가 보이는 곳 |
|---|---|---|---|
| 기록 남기기(출처 포함) | "기록 남길게. 출처는 「주간 회의 메모」 파일이야. …(내가 쓴 글 그대로)" | 대화 | 기록 탭 — 기록 위에 출처가 붙습니다. 출처를 말하지 않으면 「출처 미확인」 |
| 후보 뽑기 | "방금 기록에서 후보 뽑아 줘" | 대화 | 오늘 탭 「아직 안 정한 문장」 |
| 후보 확정 | "첫 번째는 남길게. 두 번째는 빼 줘. 세 번째는 이렇게 고쳐서 남길게: …" 또는 웹 [원문과 대조하기] | 대화 또는 웹 | 질문 탭 한 장 「내 판단」 · 오늘 탭 상태 막대 |
| 질문 세우기 | "이 질문 남길게: 언제 표준으로 가고 언제 직접 만드나?" | 대화 | 질문 탭 |
| 축에 기록 붙이기 | 축 항목이 먼저 있어야 합니다. ① "축 항목 「범위 관리」 만들어 줘" → "적용해 줘" ② "방금 기록을 「범위 관리」 축에 붙여 줘" | 대화(① 적용은 웹 서랍에서도) | 구조 탭 › 항목 › 축 서랍의 「붙은 기록」. 기록 탭·지도에는 축 이름이 나오지 않습니다 |
| 결정 남기기 | "이 두 판단을 근거로 결정 하나 제안해 줘: 「A사 견적은 표준으로 간다」" → "적용해 줘" | 대화로 제안, 적용은 대화 또는 웹 | 구조 탭 › 항목 (새 탐색: 오브젝트 탭) |
| 기준 세우기 | "확정한 판단 두 개로 기준 하나 제안해 줘: …" → 서랍에서 확인 → "적용해 줘" → "이 기준 확정할게" | 대화로 제안, 적용·확정은 대화 또는 웹 | 구조 탭 › 항목 서랍 — 근거·승격 조건 충족 여부 |
| 내 오브젝트 만들기 | "프로젝트를 따로 쌓고 싶어. 결정과 이어지게 정의 제안해 줘" → AI 가 보여 주는 미리보기 확인 → "적용해 줘" | 대화 | 구조 탭 › 구조 정의(새 탐색: 「내 구조 설정」) — 구분 「직접 추가」 |
| 표준 편입 고르기 | 말하지 않습니다. 웹에서 고릅니다 | 웹 — 구조 정의 › 표준 편입 미리보기 › 편입·보류·거절 | 같은 화면의 상태 표시. **이미 쓰던 계정만** 고릅니다 — 새 계정은 처음부터 표준이 들어 있습니다 |
| 남의 글이었다고 표시하기 | "이 기록은 내가 쓴 게 아니라 남의 글이었어. 기록 정보 고쳐 줘" | 대화 | 기록 탭 — 그 기록은 판단 근거로 쓸 수 없게 됩니다. 그 기록에서 후보를 이미 뽑았다면 바꿀 수 없습니다 |
| 오브젝트 보관·되살리기 | "프로젝트 오브젝트 보관해 줘" — AI 가 먼저 그 오브젝트의 항목 수와 그 오브젝트를 가리키는 다른 필드 수를 알려 줍니다. 되살릴 때 "보관한 프로젝트 오브젝트 다시 꺼내 줘" | 대화 | 보관하면 구조 정의(새 탐색: 「내 구조 설정」) 목록에서 빠지고, 되살리면 다시 보입니다. 항목은 지우지 않습니다. 보관한 오브젝트 목록은 대화에서 "보관한 오브젝트 보여 줘". 표준(축·결정·기준)과 아직 적용하지 않은 제안은 보관할 수 없습니다 |
| 적용 전 제안 다시 보기 | 제안한 그 대화에서 "아까 제안한 프로젝트 정의 다시 보여 줘" — AI 가 그 제안을 콕 집어 다시 읽습니다 | 대화 | 대화에서만. 적용 전 새 오브젝트 제안은 화면 목록에 나오지 않습니다 |
| 표시 이름 정하기 | "내 표시 이름을 「새벽」으로 바꿔 줘" 또는 웹 이름 입력 화면 · 계정 메뉴 「표시 이름 바꾸기」 | 대화 또는 웹 | 「나」 홈 |
| 사람 남기기 | "사람 이름표 하나 만들어 줘: 「옆팀 리드」" — 이름표 하나만(별칭 권장) | 대화 또는 웹(「나」 › 사람) | 「나」 › 사람 (새 탐색 수락 뒤) |
| 출처 요약/반응 남기기 | "「주간 회의 메모」 출처에 내 반응 남길게: …" · 확인한 뒤 "이 반응 검토 완료로 해 줘" | 대화 또는 웹(출처 상세) | 「나」 출처별 탭 · 출처 상세 — 처음엔 「검토 대기」 (새 탐색 수락 뒤) |
| 내 PC 연결하기(연결 장치) | 말하지 않습니다. 웹에서 합니다 | 웹 — 계정 메뉴 「연결 장치」 › 장치 이름 적고 연결 → 한 번만 보이는 토큰을 PC 의 로컬 에이전트 연결 단계에 붙여 넣기 | 연결 장치 화면 — 상태·만료 예정·허용 규칙. 토큰은 대화·문서·메신저에 붙여 넣지 않습니다 |
| 활동 보기 | "최근 내 활동 보여 줘" · "「옆팀 리드」와 연결된 활동 보여 줘" · "날짜 미확인 활동만 보여 줘" | 대화 또는 웹 | 「나」 홈 활동 집계 › 활동 목록 · 활동 상세 · 사람·출처 상세. 원문은 없고 행동·날짜·별칭·출처 종류만 있습니다 |
| 「나」 집계 보기 | "최근 30일 내 활동 집계 보여 줘"(7일·90일·전체도) | 대화 또는 웹 | 「나」 홈 — 행동별·축별·자주 반응한 사람·출처 구성·날짜 미확인. 정해진 계산 규칙이고 성향 평가가 아닙니다 |
| PC 에서 보낸 글 승인하기 | 말하지 않습니다. 대화에서는 "승인 대기에 뭐 있어?"로 목록·본문만 봅니다 | 웹 — 「나」 홈 [승인 대기] › 글 열기 › [승인] · [제외] | 승인하면 기록 탭에 출처 「연결 장치에서 가져옴」으로 들어갑니다. AI 요약은 승인해도 AI 생성 표시가 남고 인용할 수 없습니다 |
| 원문 보기 | 말하지 않습니다 | 원문을 보관한 PC 의 브라우저 — 활동 상세 [원문 열기 · 이 PC] → 로컬 화면의 [원문 열기] | 그 PC 의 로컬 에이전트 화면. 서버는 원문을 가져오지 않습니다 |
| 계정 삭제 요청 | 웹 계정 메뉴 「개인정보 요청」에 "계정을 삭제해 주세요" 한 줄. 대화에서 "계정 삭제 요청 보내 줘"라고 해도 됩니다(보낼 글을 먼저 확인) | 웹 또는 대화 | 계정 메뉴 「내 문의」 — 절차는 [11. 처리방침](11-privacy.md) 3절 |

AI 는 제안만 합니다. 적용·확정·남기기·검토 완료는 내가 말하거나 버튼을 눌러야 됩니다. 승인 대기 글의 승인·제외는 웹 버튼으로만 됩니다.

## 4. 화면 다섯 탭

| 탭 | 보이는 것 |
|---|---|
| 오늘 | 아직 안 정한 문장(질문별·기록별), [원문과 대조하기], 다음 할 일 / 오른쪽에 최근 기록과 원문 읽기 판 |
| 질문 | 질문 하나씩 한 장 — 내 판단 · 아직 안 정한 문장 · 남기지 않은 문장 · 연결된 기록 |
| 기록 | 기록 원문 전체와 그 기록에서 나온 문장. 기록마다 출처(파일·웹 주소·대화)가 붙고, 없으면 「출처 미확인」. 위쪽 필터로 출처별로 봅니다 |
| 구조 | 두 보기 — **항목**: 내가 정의한 자료(기준·결정·축 …)가 카드로, 누르면 오른쪽 서랍에 본문·근거·이력·제안 · **구조 정의**: 내 오브젝트·필드·관계를 목록과 그림으로, 표준 편입 미리보기 |
| 지도 | 흐름 세 열 — 들어오는 것(후보 없는 기록) · 내 손 대기(아직 안 정한 문장) · 쌓이는 재료(내 판단·기준) |

맨 위 막대는 오늘의 상태(내 판단·아직 안 정함·남기지 않음·후보 없는 기록 비율)이고, 그 아래 질문마다 미결정 수와 [한 장]이 있습니다.

**새 탐색** — 계정 메뉴 「새 탐색으로 바꾸기」에서 한 번 수락하면 화면이 바뀝니다.
- 「나」 홈이 첫 화면입니다. 표시 이름, 확정한 판단·기준·결정 개수와 최근 목록, 사람·출처·지도로 가는 길, 출처별 탭(그 출처의 내 기록·내 요약·내 반응)이 있습니다.
- 「나」 홈 맨 위 설명: "연결된 활동과 기록을 정해진 계산 규칙으로 보여 줍니다. 활동량을 성격이나 능력으로 해석하지 않습니다. AI가 작성한 설명은 승인 대기에 표시합니다." 그 아래 활동 집계(기본 최근 30일, 7일·90일·전체, 한국 시간 오늘 포함)와 [승인 대기] 버튼(승인 전 글 수)이 있습니다.
- 계정 메뉴 「연결 장치」에서 내 PC 의 로컬 에이전트를 연결합니다. 원문·실명·주소는 PC 에 남고, 서버엔 행동·날짜·별칭·출처 종류 같은 구조화 정보와 내가 승인할 글만 옵니다.
- 「오늘」은 탭 줄에서 빠집니다. 「나」 홈의 [오늘 할 일]로 엽니다(아직 안 정한 문장 수가 붙습니다).
- 「오브젝트」 탭에 모든 오브젝트가 코어 → 표준 → 직접 추가 순으로 나옵니다.
- 「구조 정의」 보기는 계정 메뉴 「내 구조 설정」으로 옮깁니다.
- 데이터는 바뀌지 않습니다. 표준 편입과는 따로입니다. 되돌리는 화면은 없습니다.
- 새로 가입한 계정은 처음부터 새 탐색입니다.

## 5. 웹에서 할 수 있는 것과 없는 것

- **할 수 있는 것**: 보기, 후보 결정(남기기·고쳐서 남기기·남기지 않기·되돌리기), 기준 결정, AI 가 낸 제안의 적용·제외, 표준 정의 편입·보류·거절(「구조 정의」), 표시 이름 정하기·바꾸기, 새 탐색 수락, 사람·출처·출처 요약/반응 추가·고치기·지우기와 검토 완료(새 탐색 수락 뒤), 연결 장치 연결·토큰 재발급·연결 해제·허용 규칙 바꾸기와 승인 대기 승인·제외·활동 보기(새 탐색 수락 뒤), 계정 메뉴 「문의 보내기」·「개인정보 요청」·「내 문의」.
- **없는 것**: 기록·질문·후보·기준 **추가**, 오브젝트 보관·되살리기, 적용 전 정의 제안 보기. 전부 연결한 AI 대화에서 합니다. 활동 추가·고치기·지우기도 없습니다 — 활동은 연결 장치만 보냅니다. 원문은 어디서도 바뀌지 않습니다.

## 6. 로그아웃

[로그아웃] → 시작 화면 "로그아웃했어요". 거기서 [로그인]을 누르면 계정을 다시 고를 수 있습니다. 그냥 주소로 들어가면 로그인 서버가 기억한 계정으로 바로 들어가요.

## 7. 막힐 때

| 현상 | 뜻 |
|---|---|
| "대시보드에서 표시 이름을 정해 주세요" | 표시 이름을 아직 정하지 않았습니다. 웹에 로그인해 이름을 정하거나, 대화에서 "내 표시 이름을 …로 해 줘" |
| "후보의 근거 구절이 저장된 원문과 일치하지 않아 남길 수 없어요" | AI 가 인용을 틀리게 보냈습니다. 대화에서 "후보 다시 뽑아 줘" |
| "다른 곳에서 먼저 바뀌었어요" | 대화와 웹에서 같은 것을 동시에 바꿨습니다. 새로 고침 |
| 「확정 전 재검토」 · "근거 기록의 작성자를 확인할 수 없어…" · "근거 기록이 원문 그대로가 아니라…" | 그 문장의 근거 기록이 인용 조건(내가 직접 쓴 원문 그대로)을 못 채웁니다. 남기지 않기·아직 안 정함은 됩니다. 작성자·가공 방식 표시가 **실제로 틀렸을 때만** 연결한 AI 대화에서 "이 기록은 내가 직접 쓴 원문 그대로야. 기록 정보 고쳐 줘"라고 말하세요 — AI 가 기록 정보를 고칩니다. 화면 안내에 영어 도구 이름이 보여도 내가 직접 부를 필요는 없습니다 |
| 「확정 전 재검토」 · "근거 기록이 남이 쓴 글이라…" · "근거 기록이 삭제돼…" | 그 후보는 확정할 수 없습니다. 남기지 않기·아직 안 정함만 됩니다 |
| "이 기록을 근거로 한 후보가 …개 있어 본인 원문이 아니라고 바꿀 수 없어요" | 이미 후보를 뽑은 기록은 「남의 글」 등으로 바꿀 수 없습니다. 후보는 남기지 않기로 두고, 꼭 고쳐야 하면 「문의 보내기」 |
| "표준 필드는 뺄 수 없어요" · "표준 필드의 key·value_type·대상·multiple·required 는 바꿀 수 없어요" · "표준 오브젝트의 key 는 바꿀 수 없어요" · "표준 오브젝트는 삭제·보관할 수 없어요" | 편입한 표준 정의(「표준 정의 보호」)의 표준 부분을 바꾸거나 보관하려 했습니다. 표준 정의는 label(표시명)만 바꿀 수 있어요. 필드·선택지는 더할 수 있어요 |
| "적용 전 제안은 보관할 수 없어요" | 아직 적용하지 않은 정의 제안이라 보관할 것이 없습니다. 그대로 두거나 새 제안으로 덮으세요 |
| "이 사람은 연결돼 있어 지울 수 없어요(…)" | 그 사람이 활동·기록·항목에 연결돼 있습니다. 서버는 연결을 몰래 끊지 않습니다. 별칭은 바꿀 수 있어요 |
| "AI 요약으로 보관한 기록은 출처 판정을 바꿀 수 없어요" | 승인 대기에서 승인한 AI 요약은 내가 쓴 원문으로 바꿀 수 없습니다. 직접 쓴 글은 새 기록으로 남기세요 |
| "지금은 서버가 장치에서 보내는 자료를 받지 않아요(준비 중)" | 서버가 아직 장치 자료를 받지 않습니다. 연결은 미리 해 둘 수 있고, 보낼 자료는 PC 에 남아 있습니다 |
| "연결된 장치가 5대라 더 연결할 수 없어요" | 쓰지 않는 장치를 연결 해제한 뒤 연결하세요 |
| 「토큰 만료 · 재발급 필요」 | 장치 토큰이 90일이 지나 만료됐습니다. 연결 장치 화면에서 [토큰 재발급] → PC 의 로컬 에이전트에 새 토큰을 넣어 다시 연결 |
| "승인 대기 글의 승인이 지금 꺼져 있어요" | 서버가 아직 승인을 받지 않습니다. 대기 글은 그대로 남고, 제외는 됩니다 |
| "더 새 개정이 들어와서 이 개정은 승인할 수 없어요" | PC 에서 같은 글이 다시 바뀌어 들어왔습니다. 최신 개정을 열어 승인하세요 |
| "지금은 승인할 수 없어요(만료됐거나 이미 처리됐어요)" · "이미 처리한 승인 대기예요" · "보관 기간이 지난 승인 대기예요" | 30일이 지나 만료됐거나 이미 승인·제외했습니다. 목록을 새로 고치세요 |
| [원문 열기 · 이 PC] 가 안 열림 | 원문을 보관한 그 PC 에서만 열립니다. 그 PC 에서 로컬 에이전트의 원문 보기를 켰는지, 버튼 아래 「로컬 연결 포트」가 같은지(기본 8790) 확인하세요 |
| 첫 응답이 느림 | 무료 서버가 깨는 중(30~60초) |
| 로그인했는데 빈 화면 | 아직 기록이 없습니다. 대화에서 기록 1편부터 |

용어는 [10. 말 뜻](10-words.md).

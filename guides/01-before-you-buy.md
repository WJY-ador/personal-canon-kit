# 01. 사기 전에 — 나한테 맞는지

## 이런 분께 맞습니다

- 메모·저장 글·AI 대화·업무 경험이 쌓여 있는데, 필요할 때 내 자료를 찾아 다시 쓰기 어렵다.
- 회고·글쓰기·의사결정 때 이전 자료를 찾느라 같은 맥락을 다시 설명한다.
- 완성 화면을 대신 만들어 주는 외주보다, 내 데이터를 내가 갖고 스스로 운영할 틀을 원한다.
- 처음 연결할 내 기록 1편과, 다시 찾아보고 싶은 질문 1개를 고를 수 있다. (질문이 없어도 메모 1편부터 시작할 수 있습니다)

## 이런 경우엔 보류를 권합니다

- 전부 대신 구축·운영해 주길 원한다 — 이 패키지는 셀프 운영 틀입니다.
- 회사 원자료를 제한 없이 연결하거나 팀 권한 관리가 필요하다 — 개인용입니다.
- 다시 꺼내 쓸 일이 드물고 지금 방식에 만족한다 — 억지로 늘릴 필요가 없습니다.

## 받는 것

`manifest.json` 의 `files` 가 전체 목록입니다. 묶음으로는:

| 묶음 | 내용 |
|---|---|
| 대시보드 | `canon.py serve` — 내 탭만 보이는 읽기 전용 화면 |
| 명령 | `canon.py` — 기록·정리·탭·점검·백업·복구 |
| 양식 | `templates/` — 프로필·질문·자료·탭·후보·일지·issue-log |
| 가이드 | `guides/` — 이 문서 포함 8개 |
| 스킬 | `.claude/skills/` — 설정 대화·기록·정리·점검/복구 |
| 샘플 | `sample-data/` — 가짜 데이터 |
| 버전 | `manifest.json`·`CHANGELOG.md` |

## 내가 직접 해야 하는 것

- Python 3.9 이상과 Claude Code 설치·로그인 (가이드 02·03)
- 연결할 자료 고르기, 민감·회사·타인 자료 빼 두기
- AI 가 낸 후보를 원문과 대조해 확인·제외하기
- 가끔 `doctor` 로 점검, 깨지면 가이드 07 따라 복구

## 필요한 것 (별도)

- **Claude Code 구독** — 정리 기능이 씁니다. 패키지 가격에 포함되지 않습니다. 없으면 `--no-model` 로 일부만 씁니다.

## 지원 환경 (지원표)

| 환경 | 핵심 흐름 | 상태 |
|---|---|---|
| macOS (Apple Silicon) + Python 3.9+ | 설치·설정·기록·정리·화면·복구 | 제작 환경에서 시험함 |
| Windows 11 네이티브 + Python 3.9+ | 같은 범위 | **미검증** — 코드는 대응했지만 실제 시험 전 |
| Windows WSL | — | **미검증·미결정** (네이티브와 따로 취급) |
| 예약 실행·알림·자동 수집 | — | 이 버전에 없음 |

# personal-canon-kit (가칭)

> 내 관심 주제에서 시작해, 매일 적는 기록이 내 판단으로 쌓이고, 그걸 내 화면에서 보는 개인 시스템.
> Claude Code 안에서 "이 레포 읽고 내 글이랑 목적에 맞게 세팅해 줘" 한 문장으로 시작합니다.

**상태: 초안.** 원작자 한 사람이 1년 가까이 쓰던 시스템을 남이 쓸 수 있는 꼴로 꺼내는 중입니다.
첫 사용자 한 명과 세팅을 해 보며 다듬고 있어요. 지금은 설치해도 원작자 값이 군데군데 남습니다.

## 무엇인가

세 겹입니다.

1. **방법** — 자꾸 돌아오는 주제(이 레포에선 "축"이라 부릅니다)를 먼저 정하고, 날짜별로 적고,
   적은 것 끝에 "이게 어디에 붙나" 네 줄을 달고, 반복되는 판단만 따로 모읍니다. 순서가 중요합니다.
   주제 없이 수집부터 켜면 읽을 수 없는 더미가 쌓입니다.
2. **화면** — 로컬에서 도는 대시보드. 탭은 원작자 것이 아니라 **당신이 하고 싶다고 말한 것**으로
   이름 붙고 묶입니다. 글쓰기, 모아 둔 글 읽기, AI에게 시키고 답 이어받기, 내 판단이 어디서 왔는지
   보기 같은 블록을 고르면 그것만 뜹니다.
3. **깨졌을 때** — 멈춘 걸 알아채는 점검 명령, 사건을 적는 양식, 같은 원인이 두 번이면 규칙으로
   올리는 절차. 설치까지만 있고 그 뒤가 없는 설정 모음과 여기가 다릅니다.

## 누구에게

- Claude Code를 이미 쓰는데, 세션이 끝나면 생각이 같이 증발하는 분.
- 프로젝트마다 분야가 바뀌어서 의식적으로 남기지 않으면 도구 숙련만 남는 분(컨설턴트·PM).
- 쌓아 둔 자료를 어떻게 쓸지 고민하는 시간이 자꾸 드는 분.

## 시작하기 (예정)

```bash
git clone https://github.com/WJY-ador/personal-canon-kit.git ~/personal-canon-kit
cd ~/personal-canon-kit
claude
```

그다음 Claude에게 이 한 문장.

```
SETUP_클로드에게.md 를 읽고 내 글이랑 목적에 맞게 단계적으로 세팅해 줘. 단계마다 나한테 물어보고 진행해.
```

Claude가 하는 일은 순서대로 이렇습니다.

1. 환경 진단 (맥인지, Claude Code 로그인, python, git)
2. 당신 글 읽기 — LinkedIn·Threads·블로그 글을 붙여 주면 문체·주제·믿는 사람을 **추정**하고 확인을 받습니다
3. 글에서 못 뽑은 것만 질문 — 특히 "그 주제에서 아직 답 못 찾은 질문"
4. 하고 싶은 것 묻기 → 당신 말로 탭 이름 짓기 → "이 탭 N개가 뜹니다" 보여 주고 승인 뒤 만들기
5. 원작자 값이 박힌 자리(메일 계정·알림·스케줄…)를 당신 값으로 바꾸거나 **끄기**
6. 당신 주제 하나로 끝까지 한 번 — 기록 한 편, 점검, 한 장 조립

## 하지 않는 것

- **API 키를 받지 않습니다.** 당신의 Claude Code 구독으로만 돕니다. 키 입력 칸이 없습니다.
- **서버에 올리지 않습니다.** 전부 당신 컴퓨터 안. 밖으로 나가는 건 당신이 붙여넣은 글뿐.
- **판단을 대신하지 않습니다.** 자동화는 수집·요약·점검까지. 주제를 정하고 판단을 적는 건 사람.
  원작자 실측에서 "사람 대신 판단하는 자동화"는 채택률 0이었습니다.
- **원작자 화면을 복제하지 않습니다.** 탭·묶음은 당신 것으로 새로 짓습니다.

## 전제

- macOS. 스케줄·알림·일부 수집이 맥 전용입니다. 다른 OS는 서버만 돕니다.
- Claude Code 구독. 모델 호출이 전부 `claude -p`입니다.
- 터미널을 열어 본 적 있으면 충분합니다. git은 몰라도 Claude가 대신 합니다.
